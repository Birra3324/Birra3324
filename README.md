# Birra Gemedi

I build Python API services and workflow automations, with a focus on structured data, API integrations, and practical AI features.

My current portfolio includes a FastAPI/n8n intake workflow, a document retrieval assistant, and Flutter/Firebase media-application components. I use these projects to demonstrate implementation decisions, test coverage, and failure handling. Deployment and completion status are documented per project.

- **[Vision Music](https://github.com/Birra3324/visionmusicapp):** Flutter/Firebase application work, supported by [backend](https://github.com/Birra3324/visionmusic-backend), [admin](https://github.com/Birra3324/visionmusic-admin), and [site](https://github.com/Birra3324/visionmusic-site). Public repository evidence and sanitized demonstrations describe the verified scope.
